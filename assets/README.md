# Identidad visual de ProBackUp

`probackup-logo.png` es el original de alta resolución con transparencia, generado con la herramienta integrada ImageGen. `ProBackUp.App/app.ico` contiene imágenes PNG de 16, 24, 32, 48, 64, 128 y 256 píxeles. Se usa en ambos ejecutables y en los accesos directos. El logo también está integrado en sus cabeceras.

Prompt utilizado: «Premium Windows desktop app icon for ProBackUp: a compact stack of three database/data storage layers wrapped by a bold clockwise backup arrow, unified cohesive silhouette suggesting secure recoverable data. Restrained dimensional depth, precision geometric edges, readable at 32px. Teal and cyan accents, midnight navy rounded-square tile, subtle gradients and lighting, transparent outside the tile. No lettering, wordmark, mockup, particles, tiny circuitry or watermark».
